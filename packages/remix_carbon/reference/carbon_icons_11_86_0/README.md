# Carbon Icons 11.86.0 source snapshot

This directory contains all 2,725 official 32 px SVG sources from
`@carbon/icons@11.86.0`, published from Carbon repository commit
`188d23202ec1092322dee92cf0df9d9958224ae4`.

`manifest.json` records the npm package identity and integrity, a hash for every
SVG, and a deterministic hash of the vendored tree. The original Apache-2.0
license is preserved in `LICENSE`. These reference inputs are excluded from the
published Dart package and are used only to reproduce the committed font
artifacts.

Do not edit individual SVGs. Update the pinned upstream dependency deliberately,
then regenerate the manifest, font, lock, report, and Dart provider together.
