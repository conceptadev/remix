# Radix Icons 1.3.2 source snapshot

This directory contains all 318 SVG sources from the official
`@radix-ui/react-icons@1.3.2` tag, dereferenced to commit
`bde33b13aa5848555f5512ac12155930fb4beb7d`.

`manifest.json` records the upstream identity, a hash for every SVG, and a
deterministic hash of the vendored tree. The original MIT license is preserved
in `LICENSE`. These reference inputs are excluded from the published Dart
package and are used only to reproduce the committed font artifacts.

Do not edit individual SVGs. Update the pinned upstream snapshot deliberately,
then regenerate the manifest, font, lock, report, and Dart provider together.
