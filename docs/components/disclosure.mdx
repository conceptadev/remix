`RemixDisclosure` pairs one interactive trigger with one inline content panel.
It is the standalone choice when the panels do not need the coordination that
`RemixAccordionGroup` provides.

Radix Primitives calls this component **Collapsible** and exposes Root, Trigger,
and Content parts. Remix uses the WAI-ARIA and Naked UI name **Disclosure**, with
the same anatomy represented by `RemixDisclosure(trigger:, content:)`.

## Basic usage

```dart
import 'package:flutter/material.dart';
import 'package:remix/remix.dart';

class AccountDisclosure extends StatefulWidget {
  const AccountDisclosure({super.key});

  @override
  State<AccountDisclosure> createState() => _AccountDisclosureState();
}

class _AccountDisclosureState extends State<AccountDisclosure> {
  bool expanded = false;

  @override
  Widget build(BuildContext context) {
    return SizedBox(
      width: 320,
      child: RemixDisclosure(
        expanded: expanded,
        onExpandedChanged: (value) => setState(() => expanded = value),
        trigger: const Text('Account details'),
        triggerBuilder: (context, state, child) {
          return Row(
            children: [
              Expanded(child: child!),
              Icon(state.isExpanded ? Icons.remove : Icons.add),
            ],
          );
        },
        content: const Text('Signed in as person@example.com'),
        style: DisclosureStyler()
            .padding(.all(12))
            .content(.padding(.all(12)))
            .onExpanded(
              DisclosureStyler().color(Colors.blue.shade50),
            ),
      ),
    );
  }
}
```

Omit `expanded` to use internal state. `defaultExpanded` only selects the
initial value in that uncontrolled mode. In controlled mode, the owner remains
the source of truth and may accept or reject each `onExpandedChanged` request.

## Fortal widget

```dart
import 'package:flutter/material.dart';
import 'package:remix_fortal/remix_fortal.dart';

final disclosure = SizedBox(
  width: 320,
  child: FortalDisclosure.soft(
    size: FortalDisclosureSize.size2,
    trigger: const Text('Repository details'),
    content: const Text('Three packages and twelve contributors'),
  ),
);
```

`FortalDisclosure.surface` and `FortalDisclosure.soft` provide three size
presets. Radix Themes does not ship a styled Collapsible, so these are Fortal
extensions built from the shared panel, typography, radius, and interaction
tokens rather than a claimed Radix Themes visual match.

## Styling

`DisclosureStyler` forwards top-level box methods such as `padding`, `color`,
and `borderRadius` to the trigger. Style the other parts explicitly:

- `container(...)` wraps the trigger and content as one visual panel.
- `containerEffects(...)` adds layered shadows, strokes, or backdrop blur.
- `trigger(...)` styles the interactive hit target.
- `content(...)` styles the revealed inline panel.
- `onExpanded(...)` and `onCollapsed(...)` select expansion-specific styles.
- Standard widget-state variants such as `onHovered`, `onPressed`,
  `onFocusVisible`, and `onDisabled` apply across the whole resolved spec.

The default panel transition combines a top-anchored size transition with a
fade over 200 milliseconds. Supply `animationStyle` to change its timing, or
use `AnimationStyle.noAnimation` for an immediate transition.

## Keyboard and accessibility

- Space and Enter toggle the disclosure while its trigger has focus.
- The trigger publishes button semantics and its expanded or collapsed state.
- `semanticLabel` replaces trigger-descendant semantics when the visual trigger
  does not provide a clear accessible name; `semanticHint` adds context.
- Focusable controls inside the content remain in normal traversal while open
  and are removed from traversal when collapsed.
- Collapsing while focus is inside the content returns focus to the trigger
  when the trigger remains interactive. Disabling alone does not move focus.

Radix `Collapsible.Content.forceMount` has no `NakedDisclosure` equivalent.
Without a transition the collapsed panel is unmounted immediately; with a
transition it stays mounted only until the exit animation finishes.
